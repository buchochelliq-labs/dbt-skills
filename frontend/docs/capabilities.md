# Verified native capability assumptions

Official documentation checked 2026-10-23. These references constrain the mock UX;
no API calls or account capability verification were performed. Availability remains
account-, cloud-, preview- and runtime-dependent. The companion is UOL-owned UI.

| Surface      | Official basis                                                                                                                                                                                                                                                                                                                              | Implemented boundary                                                                                                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Domains      | [Azure domains and subdomains](https://learn.microsoft.com/en-us/azure/databricks/uc-semantics/domains) support one domain and one subdomain, multiple asset memberships, and one domain/subdomain per Page.                                                                                                                                | Explicit ancestor/flatten/UOL-only projection. Deep UOL hierarchy remains canonical.                                                                                                                   |
| Domain API   | [Domain API](https://docs.databricks.com/api/domains/v1/domain) documents Beta domain operations and authorization.                                                                                                                                                                                                                         | No claim that no API exists. No live domain writes; reviewable projection/tag plan.                                                                                                                    |
| Pages        | [Pages](https://learn.microsoft.com/en-us/azure/databricks/uc-semantics/pages) distinguishes Related assets from Sources and bulk import review from resulting drafts. Owner conversations may use draft Pages.                                                                                                                             | Separate pickers, draft lifecycle and reviewed handoff. UOL withholding drafts is its own policy. Direct API publication is unsupported here.                                                          |
| Metric views | [Feature availability](https://learn.microsoft.com/en-us/azure/databricks/uc-semantics/metric-views/feature-availability), [YAML reference](https://learn.microsoft.com/en-us/azure/databricks/uc-semantics/metric-views/yaml-reference), [agent metadata](https://learn.microsoft.com/en-us/azure/databricks/uc-semantics/agent-metadata). | YAML 1.1 / Runtime 17.3 minimum for supported agent metadata; cardinality requires 18.1. Restricted structural validator, not native SQL compilation. Native fields and UOL annotations stay separate. |
| Genie Space  | [Genie Space API](https://docs.databricks.com/api/genie/v1/genie-space) defines serialized_space as full replacement and documents an ETag precondition in Public Preview.                                                                                                                                                                  | Complete snapshot, preservation of unrelated sections, mock conditional update and conflict scenario. No query execution.                                                                              |
| Authority    | [Genie Ontology](https://learn.microsoft.com/en-us/azure/databricks/genie/genie-ontology) describes modeled and inferred context and internal authority signals.                                                                                                                                                                            | No fabricated authority score, snippet publication API, indexing completion or answer-use observation.                                                                                                 |
| Access       | [UC privileges](https://learn.microsoft.com/azure/databricks/data-governance/unity-catalog/manage-privileges/privileges) distinguishes BROWSE from data access and more sensitive metadata permissions.                                                                                                                                     | Read-only simulated discovery, inspection, data, modification and management matrix. No Grant/Revoke actions.                                                                                          |
| Lineage      | [Unity Catalog lineage](https://learn.microsoft.com/en-us/azure/databricks/data-governance/unity-catalog/data-lineage) is permission-aware and has coverage limits.                                                                                                                                                                         | Hidden endpoints omitted, no labels leaked, native edges separate from semantic dependencies. Coverage gaps are unknown.                                                                               |
| Explorer     | [Catalog Explorer / ownership](https://learn.microsoft.com/en-us/azure/databricks/data-governance/unity-catalog/manage-privileges) describes catalog/schema/object navigation and object ownership.                                                                                                                                         | Dedicated metadata-only catalog, schema, table, view, metric and column screens. No data-preview tabs.                                                                                                 |

The fixture sources contain only schemas, definitions, declared expressions and
semantic mappings. SQL expressions in the metric and Genie editors are inert text.
The built frontend contains no Databricks SDK, credentials or provider-fetch calls.
