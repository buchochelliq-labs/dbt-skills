# dbt-skills

Roadmap for an open-source, local-first alternative to dbt Wizard, focused on dbt skills, project context, MCP integrations, and catalog/ontology grounding. OpenDataSuite is a broader sibling project and a possible future integration; it is not a dependency or a scope change for this work today. Implementation has not started.

See [ROADMAP.md](ROADMAP.md) for the product goals, architecture, upstream dbt skill strategy, generic catalog MCP, Unity Catalog and Genie integration plan, compatibility considerations, and priorities.
