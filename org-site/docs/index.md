## Projects

<div class="grid cards" markdown>

-   :material-source-branch-check:{ .lg .middle } **IntentumDiff**

    ---

    Semantic code review. It diffs code by *meaning* rather than by line, classifying moves, refactorings, style changes and noise across 69 languages.

    [:octicons-arrow-right-24: Overview](projects/intentumdiff.md) ·
    [Docs](https://buchochelliq-labs.github.io/intentumdiff-docs/)

-   :material-database-cog:{ .lg .middle } **OpenDataSuite**

    ---

    A Rust-first, provider-neutral control plane for analytics engineering. It starts with dbt and Databricks, and it explains every decision it makes.

    [:octicons-arrow-right-24: Overview](projects/open-data-suite.md) ·
    [Docs](https://buchochelliq-labs.github.io/open-data-suite/)

-   :material-robot-outline:{ .lg .middle } **dbt-skills**

    ---

    Local-first dbt skills, project context and catalog grounding for coding agents such as Copilot in VS Code.

    [:octicons-arrow-right-24: Overview](projects/dbt-skills.md)

-   :material-console:{ .lg .middle } **rs-rich**

    ---

    Python's `rich`, ported to Rust byte for byte, plus intuiTUIve, a reactive terminal UI framework. It can even run Doom.

    [:octicons-arrow-right-24: Overview](projects/rs-rich.md) ·
    [Docs](https://buchochelliq-labs.github.io/rs-rich-cli/)

-   :material-rocket-launch-outline:{ .lg .middle } **release-kit**

    ---

    The org's release standard: one file declares the packages and one command tags the release. It publishes to every registry.

    [:octicons-arrow-right-24: Overview](projects/release-kit.md) ·
    [Docs](https://buchochelliq-labs.github.io/release-kit/)

-   :material-view-grid-outline:{ .lg .middle } **Everything else**

    ---

    Language parsers, bindings, ontologies, plugin marketplaces and taps. Every public repository is listed in one place.

    [:octicons-arrow-right-24: All repositories](catalog.md)

</div>
