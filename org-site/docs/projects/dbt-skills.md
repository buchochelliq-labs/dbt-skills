# dbt-skills

**Local-first dbt skills, project context, MCP integrations and catalog grounding for coding agents.**

dbt-skills supplies the grounding context that an agent needs to design or revise a data
model across entities and relationships. That context includes modelling policy, naming
conventions, catalog metadata and business concepts. It does not generate or apply dbt
SQL itself.

[dbt-skills on GitHub](https://github.com/buchochelliq-labs/dbt-skills){ .md-button .md-button--primary }
