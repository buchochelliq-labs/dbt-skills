# rs-rich

**Python's [`rich`](https://github.com/Textualize/rich), ported to Rust and held to it byte for byte.**

rs-rich includes the `rich-cli` tool and a stack built on top of it: charts and diagrams,
pickers and forms, intuiTUIve (a reactive terminal UI framework), a terminal recorder,
and images in the terminal. Every parity claim is a golden test captured from the real
Python library.

[Read the documentation](https://buchochelliq-labs.github.io/rs-rich-cli/){ .md-button .md-button--primary }
[rs-rich-cli on GitHub](https://github.com/buchochelliq-labs/rs-rich-cli){ .md-button }

```sh
cargo add rs-rich
```
